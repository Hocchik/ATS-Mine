# Fase 0 — Base · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar el monorepo de Criterio con formato de errores, logs sin datos personales, Prisma con los modelos base, filtro multiempresa automático, registro de rutas clasificadas y una suite de aislamiento que detecta fugas entre empresas. Todo verificado con pruebas y una CI lista para correr.

**Architecture:** Monorepo con pnpm: `packages/shared` (Zod), `apps/api` (Express 5 + Prisma 6), `apps/web` (esqueleto React 19 + Vite) y `services/ai` (esqueleto Python + FastAPI). La API se arma con `crearApp()` a partir de módulos. Cada ruta se registra con `registro.definir()`, que la clasifica (`PUBLICA` | `TENANT`). Una ruta `TENANT` exige sesión, corre dentro de un contexto `AsyncLocalStorage` con la empresa activa y debe declarar un escenario de aislamiento. Una extensión de Prisma agrega `organizacionId` a toda consulta sobre modelos multiempresa.

**Tech Stack:** Node 22 · pnpm 11 · TypeScript 5.9 · Express 5 · Prisma 6 · PostgreSQL 17 (local) · Zod 4 · pino 9 · Vitest 3 · Supertest 7 · React 19 · Vite 7 · Python 3.12 · uv · FastAPI · pytest · ruff · ESLint 9 · GitHub Actions.

> **Nota posterior a la ejecución (2026-11-17):** este plan se escribió antes de implementar. Las revisiones cambiaron varias decisiones: `MODELOS_TENANT` se deriva del schema (no se agrega a mano), las restricciones multiempresa usan AND, hay guardia de relaciones y reglas para modelos globales, `ejecutarEnTenant` es async y valida el UUID, el global-setup usa `migrate deploy` y el verificador de aislamiento tiene control positivo. La referencia vigente es la sección "Reglas que nunca se rompen" de `CLAUDE.md`.

**Diseño de referencia:** [docs/superpowers/specs/2026-11-17-criterio-ats-design.md](../specs/2026-11-17-criterio-ats-design.md) (§2.2, §2.3, §8.1, §10).

**Convenciones que fija esta fase (las usan todas las fases siguientes):**
- Rutas con **ruta completa** (`/api/vacantes/:id`) registradas en un único `Router` montado en `/`.
- Los modelos multiempresa se crean con FKs **escalares** (`organizacionId`, `vacanteId`), nunca con `connect` a `organizacion`.
- Todo modelo multiempresa lleva `@@unique([id, organizacionId])` para que otros lo referencien con clave foránea compuesta, y se agrega a `MODELOS_TENANT`.
- Las consultas Prisma se hacen con `await` **dentro** del callback de `ejecutarEnTenant` o `ejecutarComoPlataforma`.

```ts
import { z } from 'zod';

const esquema = z.object({
  NODE_ENV: z.enum(['development', 'test', 'production']).default('development'),
  PORT: z.coerce.number().int().positive().default(3000),
  DATABASE_URL: z.string().min(1),
  LOG_LEVEL: z.enum(['fatal', 'error', 'warn', 'info', 'debug', 'trace', 'silent']).default('info'),
});

export type Config = z.infer<typeof esquema>;

export function cargarConfig(env: Record<string, string | undefined> = process.env): Config {
  const resultado = esquema.safeParse(env);
  if (!resultado.success) {
    const variables = resultado.error.issues.map((i) => i.path.join('.')).join(', ');
    throw new Error(`Configuración inválida: ${variables}`);
  }
  return resultado.data;
}
```

`apps/api/src/logger.ts`:
```ts
import pino, { type DestinationStream, type LevelWithSilent, type Logger } from 'pino';

export const CAMPOS_OCULTOS = [
  'req.headers.cookie',
  'req.headers.authorization',
  'res.headers["set-cookie"]',
  '*.email',
  '*.telefono',
  '*.documento',
  '*.password',
  '*.passwordHash',
  '*.token',
  '*.textoExtraido',
  '*.textoAnonimizado',
];

export function crearLogger(nivel: LevelWithSilent, destino?: DestinationStream): Logger {
  const opciones = { level: nivel, redact: { paths: CAMPOS_OCULTOS, censor: '[oculto]' } };
  return destino ? pino(opciones, destino) : pino(opciones);
}
```

```ts
import type { CodigoError } from '@criterio/shared';

const STATUS_POR_CODIGO: Record<CodigoError, number> = {
  VALIDATION_FAILED: 400,
  UNAUTHENTICATED: 401,
  FORBIDDEN: 403,
  NOT_FOUND: 404,
  VERSION_CONFLICT: 409,
  DUPLICATE: 409,
  HAS_DEPENDENCIES: 409,
  VACANTE_CERRADA: 410,
  ORG_NO_VERIFICADA: 403,
  RATE_LIMITED: 429,
  CAPTCHA_FAILED: 400,
  ARCHIVO_INVALIDO: 400,
  YA_POSTULASTE: 409,
  INTERNAL: 500,
};

export class AppError extends Error {
  readonly status: number;
  readonly code: CodigoError;
  readonly details: unknown;

  constructor(code: CodigoError, message: string, details?: unknown) {
    super(message);
```

```ts
import type { Prisma, PrismaClient } from '@prisma/client';
import { contextoActual } from './contexto';

/** Modelos con organizacionId. Cada modelo multiempresa nuevo DEBE agregarse aquí. */
export const MODELOS_TENANT: ReadonlySet<Prisma.ModelName> = new Set<Prisma.ModelName>(['Membresia']);

const OPERACIONES_CON_WHERE = new Set([
  'findUnique',
  'findUniqueOrThrow',
  'findFirst',
  'findFirstOrThrow',
  'findMany',
  'update',
  'updateMany',
  'updateManyAndReturn',
  'upsert',
  'delete',
  'deleteMany',
  'count',
  'aggregate',
  'groupBy',
]);

const OPERACIONES_DE_CREACION = new Set(['create', 'createMany', 'createManyAndReturn']);

export class SinContextoTenantError extends Error {
  constructor(modelo: string, operacion: string) {
    super(`Consulta a ${modelo}.${operacion} sin contexto de empresa`);
    this.name = 'SinContextoTenantError';
  }
}

function asignarOrganizacion(datos: unknown, organizacionId: string): unknown {
  if (Array.isArray(datos)) return datos.map((d) => asignarOrganizacion(d, organizacionId));
  const registro = { ...((datos ?? {}) as Record<string, unknown>) };
  if ('organizacion' in registro) {
    throw new Error('En modelos multiempresa usa organizacionId escalar, no connect a organizacion');
  }
  if (registro.organizacionId !== undefined && registro.organizacionId !== organizacionId) {
    throw new Error('organizacionId no coincide con el contexto de empresa');
  }
  registro.organizacionId = organizacionId;
  return registro;
}

function impedirCambioDeOrganizacion(datos: unknown): void {
  if (datos && typeof datos === 'object' && 'organizacionId' in datos) {
    throw new Error('No se puede cambiar organizacionId');
  }
}

export function extenderConTenant(prisma: PrismaClient) {
  return prisma.$extends({
    name: 'multiempresa',
    query: {
      $allModels: {
        async $allOperations({ model, operation, args, query }) {
          if (!MODELOS_TENANT.has(model as Prisma.ModelName)) return query(args);
          const contexto = contextoActual();
          if (contexto?.modo === 'plataforma') return query(args);
          if (!contexto) throw new SinContextoTenantError(model, operation);

          const { organizacionId } = contexto;
          const a = { ...(args as Record<string, unknown>) };

          if (OPERACIONES_CON_WHERE.has(operation)) {
            a.where = { ...((a.where as Record<string, unknown> | undefined) ?? {}), organizacionId };
          }
          if (OPERACIONES_DE_CREACION.has(operation)) {
            a.data = asignarOrganizacion(a.data, organizacionId);
          }
          if (operation === 'update' || operation === 'updateMany' || operation === 'updateManyAndReturn') {
            impedirCambioDeOrganizacion(a.data);
          }
          if (operation === 'upsert') {
            a.create = asignarOrganizacion(a.create, organizacionId);
            impedirCambioDeOrganizacion(a.update);
          }
          return query(a as typeof args);
        },
      },
    },
  });
}

export type PrismaTenant = ReturnType<typeof extenderConTenant>;
```

```ts
import { Prisma } from '@prisma/client';
import { ZodError } from 'zod';
import { AppError } from './errores';

function tipoDeErrorDeCuerpo(err: unknown): string | undefined {
  if (err && typeof err === 'object' && 'type' in err && typeof err.type === 'string') return err.type;
  return undefined;
}

export function traducirError(err: unknown): AppError {
  if (err instanceof AppError) return err;

  if (err instanceof ZodError) {
    const detalles = err.issues.map((i) => ({ ruta: i.path.join('.'), mensaje: i.message }));
    return new AppError('VALIDATION_FAILED', 'Datos inválidos', detalles);
  }

  if (err instanceof Prisma.PrismaClientKnownRequestError) {
    if (err.code === 'P2002') return new AppError('DUPLICATE', 'Ya existe un registro con esos datos');
    if (err.code === 'P2025') return new AppError('NOT_FOUND', 'No encontrado');
    if (err.code === 'P2003') return new AppError('HAS_DEPENDENCIES', 'El registro tiene datos relacionados');
  }

  const tipo = tipoDeErrorDeCuerpo(err);
  if (tipo === 'entity.parse.failed') return new AppError('VALIDATION_FAILED', 'El cuerpo no es JSON válido');
  if (tipo === 'entity.too.large') return new AppError('VALIDATION_FAILED', 'El cuerpo es demasiado grande');

  return new AppError('INTERNAL', 'Error interno');
}
```

```ts
  return sesion;
```

```ts
import type { RequestHandler, Router } from 'express';
import type { PrismaClient } from '@prisma/client';
import { exigirTenant, type ResolverSesion } from './sesion';

/** PUBLICA: sin sesión. TENANT: exige sesión y corre en el contexto de su empresa. Las fases siguientes agregan INTERNA y PLATAFORMA. */
export type Acceso = 'PUBLICA' | 'TENANT';
export type Metodo = 'get' | 'post' | 'put' | 'patch' | 'delete';

export type ResultadoEscenario =
  | { tipo: 'RECURSO'; ruta: string; cuerpo?: unknown }
  | { tipo: 'COLECCION'; ruta: string; marcador: string };

export interface EscenarioAislamiento {
  /** Crea en la empresa `organizacionId` lo que la ruta expone y devuelve la petición a probar desde otra empresa. */
  preparar: (ctx: { organizacionId: string; prisma: PrismaClient }) => Promise<ResultadoEscenario>;
}

export interface DefinicionRuta {
  metodo: Metodo;
  /** Ruta completa, p. ej. `/api/vacantes/:id`. */
  ruta: string;
  acceso: Acceso;
  aislamiento?: EscenarioAislamiento;
}

export interface RegistroRutas {
  readonly definiciones: readonly DefinicionRuta[];
  definir: (router: Router, def: DefinicionRuta, ...handlers: RequestHandler[]) => void;
}

export function crearRegistro(resolverSesion: ResolverSesion): RegistroRutas {
  const definiciones: DefinicionRuta[] = [];
  const guardiaTenant = exigirTenant(resolverSesion);
  return {
    definiciones,
    definir(router, def, ...handlers) {
      if (def.acceso === 'TENANT' && !def.aislamiento) {
        throw new Error(
          `La ruta TENANT ${def.metodo.toUpperCase()} ${def.ruta} no tiene escenario de aislamiento`,
        );
      }
      definiciones.push(def);
      const cadena = def.acceso === 'TENANT' ? [guardiaTenant, ...handlers] : handlers;
      router[def.metodo](def.ruta, ...cadena);
    },
  };
}
```

```ts
import { randomUUID } from 'node:crypto';
import express, { Router } from 'express';
import helmet from 'helmet';
import type { Logger } from 'pino';
import { pinoHttp } from 'pino-http';
import { manejadorErrores, rutaNoEncontrada } from './http/manejador-errores';
import { crearRegistro, type RegistroRutas } from './http/registro';
import type { ResolverSesion } from './http/sesion';

  logger: Logger;
  resolverSesion: ResolverSesion;
  modulos: readonly Modulo[];
}

export function crearApp({ logger, resolverSesion, modulos }: DependenciasApp) {
  const app = express();
  app.disable('x-powered-by');
  app.set('trust proxy', 1);
  app.use(helmet());
  app.use(
    pinoHttp({
      logger,
      genReqId: (_req, res) => {
        const id = randomUUID();
        res.setHeader('X-Request-Id', id);
        return id;
      },
    }),
  );
  app.use(express.json({ limit: '100kb' }));

  const registro = crearRegistro(resolverSesion);
  const router = Router();
  for (const modulo of modulos) modulo({ registro, router });
  app.use(router);

  app.use(rutaNoEncontrada);
  app.use(manejadorErrores);
  return { app, registro };
}
```

```ts
import type { PrismaClient } from '@prisma/client';
import type { Express } from 'express';
import request from 'supertest';
import type { DefinicionRuta } from '../../src/http/registro';
import { crearMembresia, crearOrganizacion, crearUsuario } from '../fabricas';

export interface FalloAislamiento {
  ruta: string;
  motivo: string;
}

export type SesionPara = (ids: { usuarioId: string; organizacionId: string }) => Promise<Record<string, string>>;

export async function verificarAislamiento(opciones: {
  app: Express;
  definiciones: readonly DefinicionRuta[];
  prisma: PrismaClient;
  sesionPara: SesionPara;
}): Promise<{ revisadas: number; fallos: FalloAislamiento[] }> {
  const fallos: FalloAislamiento[] = [];
  const rutasTenant = opciones.definiciones.filter((d) => d.acceso === 'TENANT');

  for (const def of rutasTenant) {
    const nombre = `${def.metodo.toUpperCase()} ${def.ruta}`;
    if (!def.aislamiento) {
      fallos.push({ ruta: nombre, motivo: 'sin escenario de aislamiento' });
      continue;
    }

    const duena = await crearOrganizacion();
    const intrusa = await crearOrganizacion();
    const persona = await crearUsuario();
    await crearMembresia(persona.id, intrusa.id, 'OWNER');

    const escenario = await def.aislamiento.preparar({ organizacionId: duena.id, prisma: opciones.prisma });
    const cabeceras = await opciones.sesionPara({ usuarioId: persona.id, organizacionId: intrusa.id });

    let peticion = request(opciones.app)[def.metodo](escenario.ruta).set(cabeceras);
    if (escenario.tipo === 'RECURSO' && escenario.cuerpo !== undefined) {
      peticion = peticion.send(escenario.cuerpo as object);
    }
    const res = await peticion;

    if (escenario.tipo === 'RECURSO' && res.status !== 404) {
      fallos.push({ ruta: nombre, motivo: `esperaba 404 desde otra empresa, recibió ${res.status}` });
    }
    if (escenario.tipo === 'COLECCION') {
      if (res.status >= 400) {
        fallos.push({ ruta: nombre, motivo: `la colección respondió ${res.status}` });
      } else if (res.text.includes(escenario.marcador)) {
        fallos.push({ ruta: nombre, motivo: 'la respuesta incluye datos de otra empresa' });
      }
    }
  }

  return { revisadas: rutasTenant.length, fallos };
}
```

```sh
#!/bin/sh
# Bloquea commits con secretos. Si gitleaks no está instalado, avisa y deja pasar.
if command -v gitleaks >/dev/null 2>&1; then
  gitleaks git --pre-commit --staged --redact --no-banner || {
    echo "gitleaks encontró posibles secretos en lo que vas a commitear. Revísalo antes de continuar."
    exit 1
  }
else
  echo "Aviso: gitleaks no está instalado (winget install Gitleaks.Gitleaks). Se omite el escaneo de secretos."
fi
```
